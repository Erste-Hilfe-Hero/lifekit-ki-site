# Store requirements snapshot — September 2026

Engineering gates in v5.4 assume:

- Google Play new apps and updates target Android 16 / API level 36 or later.
- Apple App Store uploads use Xcode 26 or later and an iOS 26-family SDK or later.
- Updated age-rating questionnaires, privacy/data-safety disclosures, account deletion and support/legal URLs must be completed against the final production configuration.

This file is a release snapshot, not a substitute for checking the current Apple/Google requirements immediately before submission.
