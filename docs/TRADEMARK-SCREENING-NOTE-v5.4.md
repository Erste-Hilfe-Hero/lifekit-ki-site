# Nyrathen — preliminary name screening note

A normal web search performed for the v5.4 release candidate did not surface a clearly identifiable current software/game trademark result for the exact word **Nyrathen**. This is not a legal clearance search and cannot prove availability.

Before commercial launch the publisher must run an exact and similarity search in TMview/EUIPO plus relevant national registers (including DPMA for Germany), review the relevant Nice classes for downloadable software/games/online services, and obtain professional advice if potentially similar earlier rights appear. The production evidence gate therefore remains false until that review is actually completed and dated.
