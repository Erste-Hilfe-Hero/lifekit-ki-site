# Nyrathen v5.7 beta release notes

Closed beta of the Production RC.

Focus areas:
- multiplayer stability and reconnect/failover
- hard long-term account progression
- dungeon/boss combat and 105 Account-XP dungeon-boss reward

Known release gates not satisfied by a beta upload alone:

- uninterrupted 6–24h endurance evidence
